# Concept Landing Starter

A small React starter for fast concept websites.

The main idea:

- change `src/styles/tokens.css` to create a new visual direction;
- keep reusable UI in `src/components/ui`;
- use `src/App.tsx` as a living component showcase;
- copy the project when starting a new concept project.

## Commands

```bash
npm install
npm run dev
```

## Suggested Workflow

1. Duplicate this folder for a new concept.
2. Update brand tokens in `src/styles/tokens.css`.
3. Check the component showcase in the browser.
4. Build the real landing page from the same components.
